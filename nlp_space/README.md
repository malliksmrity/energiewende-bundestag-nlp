# Energiewende speech analyzer

Paste German text: energy terms are highlighted (the project's word list, as in the spaCy pipeline) and a TF-IDF plus logistic regression model guesses the party from word choice. Runs in your browser; nothing is sent anywhere. The model is weak (held-out accuracy about 0.50) and is a teaching demo.

Code and notes: https://github.com/malliksmrity/energiewende-bundestag-nlp
